Offline file sharing between phones and computers.

Flip transfers files, folders, and clipboard text directly across your local network. Transfers move at full local Wi-Fi speeds without cloud servers, user accounts, or internet connections.

Technical Architecture

Core protocol rules and network operational parameters.

Local Socket Streaming

Streams data directly to disk in 64 KB memory chunks. Eliminates memory buffering bottlenecks on files of any size.

Proximity Pairing

Discovers nearby devices using Bluetooth Low Energy (0xFD01 and 0xFD02 service IDs) or dynamic camera QR code scanning.

Batch Transfer Approvals

Prompts the receiver once for an entire folder or multi-file queue rather than interrupting for each individual file.

Transfer Resumption

Saves verified byte offsets on disk. If Wi-Fi disconnects, the receiver streams only remaining missing bytes without duplicate files.
