Installation & Setup Guide

Follow these platform instructions to install, verify checksums, and configure network permissions for Flip.

🤖

Android Installation (.apk)

1. Download the APK

Tap Download Flip.apk on your Android smartphone or tablet (requires Android 10+ / API 29–36).

2. Enable Installation from Unknown Sources

When prompted by your browser (e.g. Chrome), tap Settings and toggle Allow from this source to proceed with local sideloading.

3. Google Play Protect Prompt

Because Flip is distributed directly without Google Play Store tracking, Play Protect may prompt with "Unrecognized app". This is normal for all directly distributed APKs. You can verify the signing certificate fingerprint using apksigner verify --print-certs Flip.apk before installing. Tap More details → Install anyway to proceed.

4. Grant Permissions

Upon initial launch, allow Nearby devices / Bluetooth (for zero-latency BLE discovery) and Camera (only required if scanning pairing QR codes).

🪟

Windows Installation (Setup Wizard or Portable)

1. Choose Setup Edition or Portable Executable

Flip-Setup-1.0.0.exe: Installs Flip into your user profile with Start Menu shortcuts and automatic uninstaller.
Flip.exe (Portable): Zero installation required. Simply place it on your desktop, Documents folder, or USB flash drive and run.

2. Windows SmartScreen Prompt

If Windows SmartScreen displays "Windows protected your PC" (standard for newly released independent executables), click More info and check that the publisher matches Adinoyi Raji, then click Run anyway.

3. Windows Defender Firewall Configuration

When Flip starts, Windows Firewall prompts for network access for Flip.exe.

Network Safety Notice: Allow Flip on Private networks (home/office Wi-Fi). If you also use your phone's personal mobile hotspot, you may check Public networks—Flip protects your PC by requiring an explicit interactive approval prompt and a one-time connection token for every incoming device session before any file transfer can occur.

4. Pairing with Android

Make sure your PC and phone are on the same Wi-Fi network (or connect your PC to your phone's mobile hotspot). Flip will automatically discover nearby devices via BLE or by pointing your webcam at the phone's QR code.
